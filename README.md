## The entry

One sentence pitching a bizarre startup idea that sounds absurd until you
realise it would actually sell. `main.py` writes that one sentence to
`/output/entry.txt` — deterministically, with no network and no dependencies
beyond the Python standard library.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program validates its own output against the gate before writing: 1–200
characters, a single line, UTF-8, not only whitespace.
